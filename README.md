# Projet Cinéma

Site web de consultation de films utilisant l'API OMDb (HTML, CSS, JavaScript).

## Lien du dépôt GitHub

https://github.com/C0definger/projet-cinema

## Pages

- `index.html` : films tendances et bouton pour charger plus de films de 2024
- `search.html` : recherche de films en temps réel
- `movie.html` : détails d'un film

## Lancer le projet

Le projet utilise les modules JavaScript, qui ne fonctionnent pas en ouvrant les fichiers par double-clic.
Il faut un serveur local : dans VS Code, installer l'extension **Live Server**, puis clic droit sur `index.html` → « Open with Live Server ».

## Organisation Git

- `main` : version finale
- `develop` : branche d'intégration
- `feature/...` : une branche par fonctionnalité
